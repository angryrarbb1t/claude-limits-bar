# limits-bar

Лимиты подписки Claude прямо в окне Claude Code: две тонкие полоски над полем ввода.

- **Слева — сессия** (пиктограмма ⑤, 5-часовой лимит), справа от полоски время до сброса: `4:16`.
- **Справа — неделя** (пиктограмма W), время до сброса: `5d` (или `4:16`, если осталось меньше суток).
- **Сессия** синяя, с 60% оранжевая, с 75% красная.
- **Неделя сравнивает расход с графиком.** Тратишь медленнее недели — синий расход, за ним серый отрезок до отметки «сколько недели прошло» (это твой запас). Тратишь быстрее — синий доходит до отметки недели, а дальше идёт перерасход: оранжевый, если обогнал неделю меньше чем на 15 п.п., красный — если больше или если съедено 80%+. Ровный расход всегда синий.
- **Переход порога** — когда полоска становится оранжевой или красной, по ней пробегает блик и всплывает короткое уведомление.
- **Стык между полосками можно тянуть** мышью: наведи на промежуток между полосками — появится тонкий разделитель. Положение запоминается.

Работает в десктоп-приложении Claude (вкладка Code) и в терминальном `claude`.

## Что нужно

- Claude Code 2.1.299 или новее.
- Вход через подписку Claude (Pro / Max). С API-ключом лимитов нет — полоски не появятся.

## Установка

Одна команда в терминале (Терминал на Mac, любая оболочка):

```bash
claude plugin marketplace add volodyatoxic/claude-limits-bar && claude plugin install limits-bar@claude-limits-bar
```

Без вопросов: ставится для пользователя и работает во всех новых сессиях — и в терминальном `claude`, и в десктоп-приложении.

Без терминала, в десктоп-приложении: нажми **+** рядом с полем ввода → **Plugins** → **Add marketplace** → `volodyatoxic/claude-limits-bar` → **Add plugin**.

Полоски появятся после первого ответа Claude в новой сессии.

## Настройки

В терминальном `claude` — `/config`, или командой `claude plugin configure limits-bar`:

| Настройка | По умолчанию |
|---|---|
| Сессия: оранжевый с, % | 60 |
| Сессия: красный с, % | 75 |
| Неделя: красный перерасход с, п.п. | 15 |
| Анимация при переходе порога | вкл |
| Уведомление при переходе порога | вкл |

## Автообновление

По умолчанию сторонние плагины сами не обновляются. Включи один раз — и Claude Code будет подтягивать новую версию при каждом запуске:

1. Запусти в терминале `claude`.
2. Набери `/plugin`, открой вкладку **Marketplaces**.
3. Выбери **claude-limits-bar** → **Enable auto-update**.

## Обновить вручную

```bash
claude plugin marketplace update claude-limits-bar && claude plugin update limits-bar@claude-limits-bar
```

## Удалить

```bash
claude plugin uninstall limits-bar
```
