# limits-bar

Лимиты подписки Claude прямо в окне Claude Code: две тонкие полоски над полем ввода.

- **Слева — сессия** (5-часовой лимит), справа от неё время до сброса: `4:16`.
- **Справа — неделя**, время до сброса: `5d` (или `4:16`, если осталось меньше суток).
- **Цвета.** Сессия: с 60% оранжевая, с 75% красная. Неделя подкрашивается только когда расход обгоняет график: оранжевая, если съедено на 15+ п.п. больше, чем прошло недели; красная, если при этом съедено 80% и больше. Ровный расход — синий.
- **Наведи мышь** — на недельной полоске проявится, какая доля недели уже прошла. Если неделя убежала дальше расхода, тень видна правее синего (запас есть); если расход обогнал неделю — тень ложится поверх синего (тратишь быстрее графика).
- **Стык между полосками можно тянуть** мышью (хватать у границы): больше места сессии или неделе. Положение запоминается.

Работает в десктоп-приложении Claude (вкладка Code) и в терминальном `claude`.

## Что нужно

- Claude Code 2.1.299 или новее.
- Вход через подписку Claude (Pro / Max). С API-ключом лимитов нет — полоски не появятся.

## Установка

Одна команда в терминале (Терминал на Mac, любая оболочка):

```bash
claude plugin marketplace add volodyatoxic/claude-limits-bar && claude plugin install limits-bar@claude-limits-bar
```

Без вопросов: ставится для пользователя и работает во всех новых сессиях — и в терминальном `claude`, и в десктоп-приложении.

Без терминала, в десктоп-приложении: нажми **+** рядом с полем ввода → **Plugins** → **Add marketplace** → `volodyatoxic/claude-limits-bar` → **Add plugin**.

Полоски появятся после первого ответа Claude в новой сессии.

## Обновить

```bash
claude plugin marketplace update claude-limits-bar && claude plugin update limits-bar@claude-limits-bar
```

## Удалить

```bash
claude plugin uninstall limits-bar
```
